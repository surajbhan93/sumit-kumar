# Sachin Kumar Portfolio

A single-page portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Edit your content

All text lives in `src/data.js`. Change the profile, experience, skills, or education there. The layout is in `src/App.jsx` and the styles are in `src/index.css`.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Go to https://vercel.com/new and import the repository.
3. Vercel detects Vite automatically. Keep the defaults:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Click Deploy. You get a live URL like `https://your-name.vercel.app`.

Every later `git push` to the main branch redeploys the site automatically.
